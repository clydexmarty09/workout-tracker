- Features:
  - Authentication system
    - User registration and login
    - bcrypt password hashing
    - Session-based authentication using cookies
  - Exercise management
    - Add and view personal exercises
  - Workout management
    - Create, edit, and delete workout routines
    - Add and remove exercises from routines
  - Workout tracking
    - Start, resume, complete, or cancel workout sessions
    - Record sets, weights, and reps
    - View completed workout history
  - Persistent data
    - Data stored in PostgreSQL
    - Users access their own workouts and exercise records
  - Responsive UI
    - Built with Tailwind CSS
  - API-driven architecture
    - API routes using Next.js App Router
    - Handles authentication, exercises, workouts, and sessions
- Tech Stack:
  - Frontend: React, Tailwind CSS, Next.js (App Router), TypeScript
  - Backend: Next.js API routes
  - Database: PostgreSQL
  - Authentication: bcrypt and session cookies
